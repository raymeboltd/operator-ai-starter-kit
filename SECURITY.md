# Security

- Keep real company context and credentials out of public repositories.
- Use synthetic examples in templates.
- Grant tools the minimum access required for one workflow.
- Separate read, draft, propose, and execute permissions.
- Require explicit approval for public, financial, sensitive, or irreversible actions.
- Rotate any secret that is committed accidentally; deleting the file is not enough.

Report security issues privately to the repository owner rather than opening a public
issue containing sensitive details.
