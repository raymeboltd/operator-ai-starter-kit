# Workflow inventory

Decompose work before automating it.

| Step | Frequency | Current owner | Input | Decision required | Output | Manual time | Failure cost |
|---|---:|---|---|---|---|---:|---|
|  |  |  |  |  |  |  |  |

## Classify each step

- **Automate:** high repetition, clear rules, cheap verification, reversible errors.
- **Assist:** useful model contribution, but judgment or review remains material.
- **Human-led:** sensitive, ambiguous, infrequent, or costly to get wrong.

## Select one first workflow

Choose the smallest high-volume workflow with a clear pass/fail result. Record a
manual baseline before introducing AI.
